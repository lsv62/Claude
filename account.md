## Чому Team, а не окремі Pro-акаунти
- **Team** дає спільний робочий простір, централізоване керування доступом, адміністрування та — що важливо для інженерного/оборонного чи промислового ПЗ — **контрактну гарантію, що ваші дані та код не використовуються для тренування моделей** за замовчуванням контент не використовується для тренування моделей за замовчуванням на плані Claude Team.
- Централізований білінг та адмін-контролі зручні навіть для маленької команди — один рахунок, керування учасниками, спільний контекст проєктів Claude Team — це план для колаборації Anthropic, який дає всій команді доступ до спільних AI-проєктів, конекторів для робочих інструментів та адмін-контролів, що зберігають інституційні знання доступними, а не розрізненими.

## Standard чи Premium seat
Це ключове рішення для розробників коду:
- **Standard seat** (~$20–25/міс. при річній оплаті): базовий функціонал, трохи більше ліміту використання за сесію, ніж у Pro Standard seats на плані Team пропонують більше використання на п'ятигодинну сесію, ніж план Pro, щоб кожен учасник команди міг отримати те, що йому потрібно від Claude.
- **Premium seat** (~$100–125/міс. при річній оплаті): суттєво вищі ліміти й **доступ до Claude Code**, що прямо стосується розробки ПЗ Premium seats включають доступ до Claude Code та збільшене використання, а також Premium seats пропонують у 6,25 раза більше використання за сесію, ніж план Pro.

**Рекомендація:** оскільки йдеться про безпосередню розробку коду (систем керування двигуном — це, найімовірніше, C/C++, embedded, реальний час), варто взяти **Premium seats для тих розробників**, які активно пишуть/рев'юють код через Claude Code, а решту (запасні місця до мінімуму) можна залишити на Standard.

### Реєстрація Team-плану
- **Хто реєструє — стає Primary Owner.** Це повинен бути тімлід або відповідальний за адміністрування, оскільки передача цієї ролі іншому потребує звернення в підтримку Anthropic.
- **Учасник не має мати особистого акаунта заздалегідь** — запрошення саме проведе його через реєстрацію/вхід.
- **Місце "займається" одразу після відправки запрошення**, навіть якщо людина ще не прийняла його — тож якщо плануєте змінити склад, скасовуйте зайве запрошення у панелі Members, щоб звільнити місце.
- Тип місця (Standard/Premium) для кожної людини обирається при запрошенні, але **потім можна змінити** — просто перейти на вищий/нижчий тип у налаштуваннях учасника (з відповідним перерахунком оплати).

### Зміна вже зареєстрованого учасника
Доступно для **Owner** та **Primary Owner** (роль Admin може керувати учасниками, але без доступу до білінгу) через **Settings → Members** — знайти потрібну людину у списку й обрати відповідну дію:
- **Заміна email одного учасника на іншого** робиться простіше через видалення старого й додавання нового — прямої функції "перейменувати" немає, але при повторному додаванні тієї ж людини її історія й акаунт зберігаються.
- **Підвищення Standard → Premium** — зручний спосіб реагувати, якщо хтось із розробників регулярно впирається в ліміти використання, не чекаючи на щотижневе скидання.
- Пам'ятайте: **новий тип місця можна обрати лише з тих, що вже куплені** для організації — тобто якщо у вас куплено рівно 1 Premium і 1 Standard, і ви захочете перевести другого учасника на Premium, спершу доведеться докупити ще одне Premium-місце.
